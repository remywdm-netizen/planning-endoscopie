Récapitulatif

Charger le fichier Excel des consultations libérales : pour chaque date d'examen, le médecin indiqué doit être présent et reçoit donc en priorité une consultation d'anesthésie ce jour-là. Colonnes attendues : Date et Médecin (initiales ou nom) ; les autres colonnes (examen, salle…) sont conservées pour information, sauf les colonnes d'identité patient (nom, date de naissance, IPP…) qui ne sont jamais enregistrées. Seule la 1re feuille est lue (.xlsx, .xls, .ods ou .csv).

Ajouter une date manuellement

Les 3 MAR titulaires assurent obligatoirement le mardi et le jeudi-Consult. 1. Modifier les initiales remplace le MAR partout (planning, indisponibilités, praticiens forcés). Le plafond « 3 / semaine » n'est utilisé que pour éviter un « Autre MAR ».

Les modifications sont enregistrées dans ce navigateur uniquement. Pour les partager ou les conserver, utiliser « Exporter la configuration », puis « Importer » sur un autre poste.
